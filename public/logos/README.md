# Company Logos Directory

Place your custom startup logo `.png` or `.svg` files here.

### File Naming Convention:
Name files using either the company's slug or lowercase name without spaces, for example:
- `stripe.png`
- `anthropic.png`
- `mistral-ai.png`
- `spacex.png`

### How It Works in TB Scout:
1. **Local PNG Override**: Place a logo in this folder matching the company slug or name in lowercase (e.g. `anthropic.png`, `stripe.png`, `spacex.png`).
2. **Auto-Discovery**: If no local PNG is found, TB Scout automatically pulls high-resolution domain favicons from the company's website.
3. **Monogram Fallback**: If an image fails to load, a stylized Notion-grade brand badge with initials is displayed.
